# قواعد التصميم — مواصفة الواجهة

**الحالة:** مسودة للاعتماد. كل القيم الرقمية تقديرية بالعين، والـ agent يقيسها من لقطات المرجع قبل التنفيذ.

## 1. القاعدة الأساسية

- الهدف: نسخة قريبة جداً من تنسيقات لوحة Admindek (الهيكل، المسافات، الألوان، الجداول، النماذج، الأزرار، الشارات، اللوحات)، مبنية بمكوّنات خاصة بنا.
- المرجع للقياس فقط: لقطات الشاشة. ممنوع نسخ أي كود أو CSS أو HTML أو JavaScript أو رسومات من المرجع (مثل الدوائر الزخرفية في صفحة الدخول)، وممنوع تنزيل صفحات الديمو.
- الأيقونات: Phosphor (ترخيص MIT).

## 2. الأدوات

React + TypeScript (الإطار: Vite أو Next.js حسب أداة التنفيذ) + Tailwind CSS + shadcn/ui + TanStack Table + React Hook Form + Zod + Recharts + Phosphor Icons + Framer Motion + PWA لتطبيق الموقع.

## 3. الخطوط

- النسخة العربية: Almarai. الوزن 400 للنص و700 للتأكيد والعناوين (300 و800 اختياريان). لا توجد أوزان وسيطة، فالتدرج البصري يعتمد على الحجم واللون.
- النسخة الإنجليزية: Inter بأوزان 300 إلى 700.
- في النسخة العربية: الأرقام والحروف اللاتينية تتجرب بالعين في الجداول المالية. لو غير متناسقة نضيف Inter للاتيني فقط.
- العناوين الكبيرة خفيفة الوزن كما في المرجع.

## 4. الألوان (متغيرات Tokens)

| العنصر | القيمة التقديرية |

| الأساسي | أزرق حوالي #4680FF |
| السايد بار | كحلي غامق حوالي #222E3C |
| خلفية الصفحة | رمادي مزرق فاتح جداً حوالي #F4F7FA |
| الكروت | أبيض |

- لكل لون نسخة ناعمة (خلفية فاتحة ونص ملوّن) للشارات والتنبيهات والأزرار الناعمة.

## 5. الهيكل العام

- **السايد بار:** كحلي غامق بعرض حوالي 260px على اليمين في العربي. لوجو في الأعلى. عناوين أقسام صغيرة بحروف رمادية. العنصر: أيقونة + اسم + سهم + عداد أو شارة اختيارية. القوائم الفرعية نصية بمستويين، والعنصر النشط له خط عمودي ملوّن ونص أزرق، والمجموعة المفتوحة لها خلفية أغمق وخط ملوّن على الحافة. حالة الطي (أيقونات فقط) تتصمم لاحقاً.
- **الشريط العلوي:** شفاف فوق خلفية الصفحة. زر طي السايد بار، بحث بـ ⌘K، ثم تبديل الثيم واللغة والتطبيقات والإشعارات (شارة خضراء بعدد) وقائمة المستخدم.
- **رأس الصفحة:** عنوان صغير ومسار التنقل تحته، وفواصل المسار تنعكس في RTL.
- **الكروت:** بيضاء بحواف 4 إلى 8px وظل شبه معدوم، وعنوان الكارت فوق خط فاصل رفيع.
- **التذييل:** خفيف.

## 6. الجداول

- **جدول بيانات:** عنوان على خلفية رمادي فاتح بحروف كبيرة سميكة صغيرة، خطوط فاصلة رفيعة، أسهم ترتيب، بحث، اختيار عدد الصفوف، وترقيم صفحات ونص «Showing x to y» في الأسفل.
- **قائمة كيانات:** كل صف كارت أبيض منفصل بمسافة بينه وبين اللي بعده، فيه صورة دائرية واسم وتحته بيان ثانوي، وشارة حالة.
- أيقونات الإجراءات (عرض، تعديل، حذف) في آخر الصف، وقد تظهر كأزرار صغيرة مفرغة.
- **خمس كثافات:** كبير جداً، كبير، افتراضي، صغير، صغير جداً.
- صف الإجمالي بخلفية زرقاء فاتحة. الصف المظلل بلون الحالة (أخضر، أصفر، أحمر) للتنبيه فقط.
- أعمدة المبالغ بمحاذاة ثابتة.
- في الجداول المالية: صف عنوان ثابت أثناء التمرير.

## 7. صفحة القائمة (النمط الأهم)

كروت مؤشرات في الأعلى (رقم + نسبة تغيّر + رسم مصغّر + عدد)، وكارت ملوّن للإجمالي أو الرصيد، ثم **تبويبات بحالات وعدادات** (الكل، مدفوع، غير مدفوع، ملغي)، ثم الجدول بالبحث والترقيم.

## 8. النماذج

- شبكة عمودين. العنوان فوق الحقل. ارتفاع الحقل حوالي 38 إلى 40px، حواف 4px، إطار رمادي.
- الحقل الإجباري بنقطة حمراء قبل الاسم. حالة الخطأ: إطار أحمر ورسالة. حالة الصحة: إطار أخضر وعلامة.
- شريط الإجراءات أسفل الكارت: حفظ (مفرغ) واعتماد وإرسال (أزرق مصمت)، وحذف بخلفية حمراء ناعمة.
- **معالج خطوات:** تبويبات خطوات وشريط تقدم أخضر وأزرار السابق والتالي والإنهاء.
- المكوّنات: قائمة منسدلة، حقل تاريخ، رافع ملفات، Checkbox، Radio، Switch بألوانها، مجموعات إدخال بإضافات.

## 9. صفحات المستندات (عرض سعر، عقد، مستخلص)

- **صفحة العرض:** شريط أيقونات إجراءات (تعديل، عرض، تنزيل، طباعة، إرسال، مشاركة)، صندوقان للبيانات (من / إلى) بإطار، جدول البنود، إجماليات محاذية لطرف الصفحة (فرعي، خصم، ضريبة، الإجمالي)، ملاحظات، وأزرار طباعة وإلغاء.
- **صفحة الإنشاء والتعديل:** حقول الرأس (رقم، حالة، تواريخ)، جدول بنود قابل للتعديل (اسم، وصف، كمية، سعر، إجمالي، حذف) مع علامة الحقل الإجباري، زر «إضافة بند» ناعم، كتلة إجماليات تتحدث لحظياً، حقل ملاحظات، اختيار العملة، وأزرار معاينة وحفظ واعتماد وإرسال.
- نسخة طباعة مستقلة بقوالب عربية.

## 10. المكوّنات الصغيرة

- **الأزرار:** مصمت، ناعم، مفرغ، رابط، معطّل، بظل. أحجام صغير وافتراضي وكبير. مجموعات أزرار. أزرار «اعتماد/رفض» ناعمة.
- **الشارات:** مصمتة وناعمة وحبّية، ونقطة ملوّنة قبل النص لحالات القوائم.
- **التنبيهات:** خلفية فاتحة بإطار بنفس اللون، وأيقونة اختيارية، وزر إغلاق.
- **Toast:** صندوق صغير بعنوان ووقت وزر إغلاق، يتكدس، وبنسخ ملوّنة.
- **التبويبات:** أفقية وكأقراص وعمودية، مع عدادات.
- **الأكورديون** والقوائم المنسدلة (عادية ومنقسمة).
- **منتقي التاريخ:** تاريخ، نطاق، تاريخ ووقت. بداية الأسبوع إعداد (السبت أو الأحد).
- **الإشعارات:** تبويبات بعدادات، تجميع (اليوم، أمس، هذا الأسبوع)، أيقونة دائرية ملوّنة بالنوع، خط جانبي لغير المقروء، وزر «تحميل المزيد».

## 11. اللوحات

كروت مؤشرات (بيضاء بلمسة لون، ومصمتة للمؤشر الأهم فقط)، رسوم مساحة بتدرج، حلقي بالإجمالي في المنتصف، أعمدة مكدّسة، مقاييس دائرية، أشرطة تقدم، قوائم نشاط بخط جانبي ملوّن، وشبكة أيقونات اختصارات.

## 12. الحركة

- القوائم المنسدلة (إشعارات، مستخدم، ثيم) تظهر تحت أيقونتها. القوائم الفرعية في السايد بار تتوسع وتنطوي. صفحة الطباعة تعرض معاينة.
- المدد: 150 إلى 250 مللي ثانية بتباطؤ خروج (ease-out).
- عند «تقليل الحركة» أو الجهاز الضعيف: بدون حركة.
- أثناء التحميل: هيكل تحميل (Skeleton) بدل الشاشة البيضاء.

## 13. قواعد RTL (إلزامية)

- ممنوع left وright وml وmr وpl وpr. المطلوب start وend وms وme وps وpe.
- dir=rtl على الجذر، ويتمرر لمكوّنات Radix (قوائم، نوافذ، تبويبات).
- السايد بار على اليمين، والخط العمودي للعنصر النشط على اليمين.
- الأسهم والأيقونات الاتجاهية تنعكس. الأيقونات العادية (حفظ، طباعة) لا.
- كل مكوّن يتجرب بنص عربي طويل وأرقام كبيرة قبل الاعتماد.

## 14. الأرقام والتواريخ

- أرقام إنجليزية (0-9) افتراضياً، مع إعداد على مستوى الشركة لتحويلها لهندية.
- بداية الأسبوع في التقويم إعداد (السبت أو الأحد).

## 15. اختلافات مقصودة عن المرجع

- حذف أزرار Feedback وإعدادات الثيم العائمة.
- هيكل تحميل بدل الشاشة البيضاء.
- الأرقام الحساسة (التكلفة والهامش والربح) تظهر بصلاحية فقط، ولا تظهر في نسخ العميل المطبوعة.

## 16. لسه ناقص

النوافذ المنبثقة (Modal)، الدرج الجانبي، السايد بار المطوي، الكروت العامة، الحالات الفاضية، الوضع الغامق، وشاشات الموبايل لتطبيق الموقع.
