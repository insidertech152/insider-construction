# Reference images index

All images are in `img/`. Each is a full-page screenshot of one page of a
reference admin dashboard. Use them to measure sizes, spacing, radii, colors
and layout. File names are as they appear in the folder.

## Start here (open these first)

| File | Use it for |
|---|---|
| List.png | The standard list page pattern: stat cards, tabs with counts, table with row actions |
| Design-reference/img/invoice edit..png | Editable line-items table, add-item button, totals block (the quote / BOQ editor) |
| invoice 3.png | Invoice document page |
| HR.png | Dashboard: KPI cards, charts, activity lists, approve / reject buttons |
| Button.png | Every button style, size and group |
| Form.png | Form layout, fields, selects, validation |
| Notification.png | Notifications page: tabs with counts, grouped by day |
| Tables.png | Overview of table styles |
