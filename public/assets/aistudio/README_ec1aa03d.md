# Project brief — ERP for finishing & decor companies (Egypt)

Arabic-first (RTL) web app. You are the implementation agent. This folder is
everything you need to start.

## Folder layout

```
README.md              this file
INDEX.md               what each reference image shows (read before opening images)
Docs/
  agent-context.md     product decisions + glossary
  design-rules.md      UI rules, tokens, components, RTL rules
img/                   reference screenshots + video frame sheets
                       (one extra image lives in Design-reference/img/: "invoice edit..png")
  video_sheet_1..3.png frame sheets from a demo recording
  Live_Demo_Preview_-_DashboardPack.mp4   the recording (optional; the sheets are enough)
```

## Read in this order

1. `Docs/agent-context.md` - never change a decision from your own
   judgment. Ask first.
2. `Docs/design-rules.md` - follow it exactly.
3. `INDEX.md` - then open the images listed under "Start here".
4. Other images in `img/` - open only the ones relevant to the component you
   are building.

## Rules

- The screenshots are for measuring only. Never copy code, CSS, HTML, JS,
  logos or illustrations from the reference product.
- Build in phases. Do only the phase you are asked to do, then stop and
  report.
- Do not choose the database yourself. The decision is still open.
- Arabic (RTL) is the default. English (LTR) is a switchable second language.
- Numbers are Western digits (0-9) by default.
